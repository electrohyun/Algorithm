# 프로그래머스 43162 네트워크

## 풀이

```js
function solution(n, computers) {
  let answer = n;

  const graph = [];

  for (const [idx, computer] of computers.entries()) {
    const temp = [];
    for (let i = 0; i < n; i++) {
      if (idx === i) continue;

      if (computer[i]) temp.push(i);
    }
    graph.push(temp);
  }

  const visited = new Array(n).fill(false);

  function dfs(node) {
    visited[node] = true;
    for (const next of graph[node]) {
      if (!visited[next]) {
        dfs(next);
        answer--;
      }
    }
  }

  for (let i = 0; i < n; i++) {
    dfs(i);
  }

  return answer;
}
```

- 행렬 `computers`를 이웃 리스트 `graph`로 변환 후 DFS.
- `answer`를 노드 수 `n`으로 시작 → 아직 방문 안 한 이웃을 만나 연결될 때마다 `answer--` → 남는 값이 네트워크 개수.
