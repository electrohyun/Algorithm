# 프로그래머스 12900 2 x n 타일링

- https://school.programmers.co.kr/learn/courses/30/lessons/12900
- 유형: DP (동적계획법) · 첫 관문

## 문제 요약

- 가로 `n`, 세로 2 인 직사각형을 채운다.
- 사용하는 타일: `1 x 2` 또는 `2 x 1` (두 종류)
- 이 타일들로 `2 x n` 을 채우는 **방법의 수**를 구한다.
- 방법의 수가 커질 수 있으므로 `1,000,000,007` 로 나눈 나머지를 반환.

### 제한

- `n` 은 60,000 이하 자연수.

### 손으로 그려볼 것 (종이 먼저)

- `n = 1` 일 때 방법의 수?
- `n = 2` 일 때 방법의 수?
- `n = 3`, `n = 4` 는? → 규칙(점화식)이 보이는가?

## 내 풀이

```js
function solution(n) {
  const dp = new Array(n + 1).fill(0);
  dp[1] = 1;
  dp[2] = 2;

  for (let i = 3; i <= n; i++) {
    dp[i] = (dp[i - 1] + dp[i - 2]) % 1000000007;
  }

  return dp[n];
}
```

## 회고

오늘의 발견:

- dp 첫 도전

잘한 점:

- 처음 도전하는 것이기 때문에 섣불리 상상력을 발휘해 도전하기보다는 dp란 뭔지 배우고 문제를 접했다.
- 기발한 발상도 중요하다고 생각하지만, 이미 배운 것을 잘 꺼내는 인출력도 코딩 테스트에 중요하진 않을까. 고민해볼 문제.
